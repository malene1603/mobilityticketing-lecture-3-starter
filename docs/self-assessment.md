# Self-assessment

Score each criterion from 0 to 2 and include one sentence of evidence.

| Criterion | 0 | 1 | 2 | Score | Evidence |
| --- | --- | --- | --- | --- | --- |
| The experiment reproduces at least one disagreement between mechanisms. | Not shown | Difference shown but not explained | Difference shown and explained |  |  |
| The recommendation identifies authority, freshness, and rebuild behaviour. | Missing | Two of three are explicit | All three are explicit |  |  |
| Corrections, refunds, and duplicate gateway references are tested. | Not tested | Some cases tested | All cases tested and interpreted |  |  |
| The selected mechanism is justified from the reporting workload. | Feature preference only | Workload mentioned | Workload and failure consequences are compared |  |  |

Request lecturer feedback only when two mechanisms remain equally defensible after you have supplied a concrete workload assumption and a failure comparison.
